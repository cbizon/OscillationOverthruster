# Reviews

The checker's review of each line's run, `YYYY-MM-DD-L0013.json` (schema:
`review.schema.json`), or of a whole night's session before lines ran
separately (`YYYY-MM-DD.json`): a verdict per claim (holds, doubtful,
broken), the attacks tried, and for doubtful or broken claims what would
resolve them. Written only by the checker.
