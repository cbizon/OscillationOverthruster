# Scheduled tasks

Prompts for the Claude Code (Code tab) scheduled tasks that run this
program on Chris's Mac. Each task is set to run only on this computer, with
`~/Projects/experiments/sequel` as its folder. Human-only.

| Task | When (proposed) | Prompt |
| --- | --- | --- |
| Session | 11 pm, until about 5 am | `session.md` |
| Checker | 5:30 am, about 45 minutes | `checker.md` |
| Debrief | 7 am | `debrief.md` |

The Mac has to be awake with the Claude app open. Sessions start long
simulations under `caffeinate`, so those keep it awake once started; the
start of each task is the fragile part, and the run conditions record it.
